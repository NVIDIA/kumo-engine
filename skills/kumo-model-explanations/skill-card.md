## Description: <br>
Inspect and interpret gradient attribution, column analysis, and sampled explanation subgraphs from a Kumo model trained in a Python notebook, locating the correct run's explanation artifacts and identifying missing or unsupported explanations without automatically retraining. <br>

This skill is ready for commercial/non-commercial use. <br>

Developers and data scientists use this skill to inspect a Kumo model's retained explanation artifacts in a notebook, explain gradient attribution scores and column-analysis cohorts, and diagnose missing or unsupported explanations without starting another fit. <br>
