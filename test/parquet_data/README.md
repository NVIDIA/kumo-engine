**FINANCIAL**

The FINANCIAL directory was generated by running the following python commands from the root of the Kumo repository.

``` python
import pandas as pd

names = [
    'ACCOUNT', 'CARD', 'CLIENT', 'DISP', 'DISTRICT', 'LOAN', 'ORDERS',
    'PREDICTION', 'TRANS'
]

for name in names:
    df = pd.read_csv(f"./test/csv_data/FINANCIAL/{name}.csv", sep=';')
    print(df)
    if name == 'TRANS':
        df['DATE'] = pd.to_datetime(df['DATE']).astype('datetime64[us]')
        df['AMOUNT'] = df['AMOUNT'].astype('float32')
    df.to_parquet(f"./test/parquet_data/FINANCIAL/{name}.parquet")
```
