| Root                  | Tables                                             | Required graph edges / fixture note                                                                                                                                                  |
| --------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ethereum-fraud/30gb` | `addresses`, `labeled_address_ids`, `transactions` | Key `addresses.address`; join transaction address IDs through `labeled_address_ids`.                                                                                                 |
| `iot23/10gb`          | `hosts`, `network_flows`                           | Key `network_flows.flow_id`; connect both `source_ip` and `destination_ip` to `hosts.host_id`.                                                                                       |
| `bccc-ids/20gb`       | `hosts`, `network_flows`                           | Key `network_flows.flow_id`; connect `src_ip` and `dst_ip` to `hosts.host_id`. For source→destination LP, explicitly select the keyed `src_ip` edge as the `FOR EACH` anchor.        |

| `noaa-ghcn/10gb`      | `observations`, `stations`                         | Connect `observations.station_id → stations.station_id`; use `observation_date` as event time. NOAA values use each element's published unit (including tenths of degrees for TMAX). |
| `yambda/100gb`        | `interactions`, `users`, `items`                   | Connect user and item IDs; use `event_time` as event time and `interaction_id` as the fact key.                                                                                      |
