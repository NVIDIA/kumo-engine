# Data governance

## Prohibited in this repository

- Real customer, account, card, merchant, transaction, or identity data
- Credentials, tokens, private checkpoints, proprietary dataset URLs
- Generated `outputs/` from local runs (gitignored)

## Allowed fixtures

- Seeded synthetic events from `tfm.data.synthetic`
- Public datasets only when a recipe documents license, access, and that they
  are optional and never fetched by default CI
- IBM TabFormer (public synthetic card transactions) via a **local** path
  (`data.path` or `TFM_TABFORMER_ROOT`). Never committed, never downloaded by CI
- Local pragmatiq books (e.g. `synth_100k_gen2_m31_seed0`) via `data.path` or
  `TFM_PRAGMATIQ_ROOT`, always entity-subsampled in recipes. Books are
  generated by a released pragmatiq from a committed world config; this
  repository does not modify pragmatiq
- PersonaLedger (CC BY 4.0) is planned, not supported; any record or notebook
  that uses it must credit it

Each dataset's role, source, licence, split, and tasks are in
[datasets](../reference/datasets.md). Results from different datasets are
never combined (ADR 0015).

Do not commit symlinks such as `data/TabFormer -> ../payment-foundation-model/...`.
A gitignored local link is an optional convenience.

## External artifacts

Reference large files via manifests. Do not Git-LFS weights onto `v2` by
default. The v1 decoder checkpoint remains on tag `v1.0.0`.
