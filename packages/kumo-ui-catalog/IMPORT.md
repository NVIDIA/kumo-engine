# Source import

Imported from `kumo-ai/kumo-ui-catalog` at
`83a38210ca0ec7a548078b9077d05bd8ce607d9d`, the source revision recorded by
`released/v2.1.0` and the successful v2.1.0 release workflow. The `v2.1.0`
tag itself points to a generated distribution commit, `97f30da02fd7afec387e9cd464c3162b661f1f70`.

Source, Storybook stories, test utilities, visual baselines, examples and
assets are retained. JetBrains Mono retains its bundled OFL notice. No
proprietary NVIDIA font files are added. Existing remote font references
and local fallback styling remain unchanged.

The package is an internal, private npm package in the public monorepo; it
is not published separately. The UI keeps `@kumo-ai/kumo-ui-catalog` imports
and resolves them with a relative file dependency. From `ui/`, run
`npm run install:catalog`, then `npm ci` and `npm run build`. Catalog-only
commands run from this directory after `npm ci --legacy-peer-deps`.

Upstream `.github/`, `.husky/` and `.claude/` automation is excluded. Build,
lint, Storybook, accessibility/coverage and visual tests are ported to
`.github/workflows/ui-catalog.yml`. Separate-repository package publishing,
release-tag rewriting, automatic screenshot-update comments and report-site
publishing are not ported. Tests and baselines remain reviewable in this
repository; no visual baselines are regenerated by this import.

Repository-wide legal/notice finalization remains tracked by #31125.
